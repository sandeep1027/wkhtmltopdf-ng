wkhtmltopdf-ng 0.14.4

Qt 6 WebEngine (Chromium) HTML-to-PDF and HTML-to-image converter.
Replacement for archived wkhtmltopdf 0.12.x (Qt WebKit).

New in 0.14.4
  - CSS position:fixed header/footer bars grow print margins before
    printToPdf, so automatic page breaks no longer put body text under
    the footer.
  - Machine-install guide: docs/USING-ON-MACHINE.txt (system Qt, not
    the portable tree). scripts/install-deps.sh installs Qt / qpdf /
    cmake for Ubuntu, Debian, Rocky/Alma/RHEL 9, Fedora, and Arch.
  - Validation tests for repeating thead, fixed chrome, local WOFF2,
    and auto page-break overlap.

New in 0.14.3
  - Remote http(s) images, CSS, and fonts load from a local file:// page
    without --enable-local-file-access (0.12 behaviour). That flag is only
    required to read other local files.
  - Image/font wait starts after loadFinished, not at convert() start, so
    a slow page load no longer skips the wait. Default budget is 3s
    (20s with --no-stop-slow-scripts). --javascript-delay is not required
    for remote images.

Download the archive that matches the machine you will run on.
Unpack the folder and run bin/wkhtmltopdf — do not copy only the binary.

Assets
  *_linux-amd64.tar.xz   Ubuntu 22.04+ / Debian 12+  (glibc 2.35)
  *_el9-amd64.tar.xz     Rocky / Alma / CentOS Stream 9  (glibc 2.34)
  *_windows-amd64.zip    Windows 10/11 (from Actions)
  *_macos.zip            macOS (experimental, from Actions)

CentOS / RHEL 7 is not supported. Use Docker (packaging/run-docker.sh).

Quick test
  tar -xJf wkhtmltopdf-ng_0.14.4_linux-amd64.tar.xz
  cd wkhtmltopdf-ng
  export QT_QPA_PLATFORM=offscreen
  export QTWEBENGINE_CHROMIUM_FLAGS=--no-sandbox
  ./bin/wkhtmltopdf --version
  ./bin/wkhtmltopdf --enable-local-file-access in.html out.pdf

Included
  CLI: wkhtmltopdf-ng, wkhtmltoimage-ng
  C API: libwkhtmltox (0.12-style names)
  Modern CSS/JS via Chromium
  dpi, smart shrinking, headers/footers, TOC, outline
  image-dpi / image-quality / lowquality
  compress, encrypt, linearize, watermark (qpdf)
  cover / toc / page objects
  merge / split / insert existing PDFs
  0.12 short options (-s -O -T -R -B -L -d -g -q -n -p -l -h -H -V)
  -v / --verbose and --log-level none|error|warn|info|verbose
  desktop viewport for print (fixes 0-width mobile CSS)
  --attach, --dump-info, TOC page numbers
  remote http(s) from file:// without --enable-local-file-access
  print margins reserved for CSS position:fixed chrome
  machine install docs and scripts/install-deps.sh

See README.md, docs/DOC.txt, and docs/USING-ON-MACHINE.txt.
